# Презентации: HTML и PDF

Каждый загружаемый файл (включая ассеты) ограничен 40 МБ (41 943 040 байт). Создание и добавление файлов в существующий пакет поддерживают HTML и PDF. PDF открывается встроенным просмотрщиком браузера; на мобильных устройствах доступность встроенного просмотра зависит от браузера. Скачивание сохраняет исходные PDF-байты.

Файлы хранятся в приватном Supabase Storage bucket `presentations`, метаданные — в `public.presentations_packages`. PDF использует `mimeType=application/pdf`, `encoding=base64`; HTML сохраняет прежний формат `text/html`, `text`. Base64 применяется только при передаче внутри приложения; Storage получает бинарный PDF. Blob URL просмотра освобождается при переключении файла и выходе со страницы.

## Выкатка через GitHub

После merge в main применить `supabase/migrations/20261009_presentations_40mb.sql` на VPS, затем обновить checkout и выполнить сборку. Миграция устанавливает лимит bucket и добавляет PDF к существующим ограничениям MIME, сохраняя доступ ассетов. Проверить, что глобальный Storage `FILE_SIZE_LIMIT` допускает не менее 41943040 байт и nginx `client_max_body_size` допускает загрузку 40 МБ с multipart overhead (рекомендуется минимум 50m; шаблон проекта уже использует 200m).

Смок в прод: создать пакет с PDF, открыть в другой сессии, скачать и сравнить исходные байты; добавить PDF в существующий HTML-пакет; проверить HTML и ассеты; принять файл ровно 40 МБ и отклонить файл 40 МБ + 1 байт. Удалить тестовые данные после проверки.
